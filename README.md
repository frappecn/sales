# Sales

即时零售运营管理系统，基于 Frappe Framework 与 ERPNext 扩展开发。

## 项目目标

围绕自营前置仓即时零售业务，逐步建设消费者下单、订单管理、仓内履约、库存协同、配送管理、售后处理与经营分析能力。首期业务范围仍以《docs/待确认事项.md》中的最终确认结果为准。

## 技术原则

- 以 Frappe Framework 和 ERPNext 为基础，优先复用官方能力。
- 自主业务优先放在本应用中，通过 DocType、Hooks、Controller、API、权限、Patch 等标准扩展机制实现。
- 尽量不修改 Frappe / ERPNext 核心代码，保持上游同步与升级能力。
- 采用模块化单体架构，首期不拆分微服务。
- 库存、销售、采购和财务数据优先遵循 ERPNext 标准业务模型，不建立相互冲突的第二套账本。
- 业务规则、技术约束和待确认事项必须明确区分；未经用户确认的业务假设不得作为已确定需求。

- `docs/待确认事项.md`：尚待业务确认的事项。

## 开发状态

项目处于基线建设阶段。任何功能在进入开发前，都应先明确业务场景、验收标准、数据权限、异常处理和测试方案。未经真实 Frappe Bench 环境验证的代码，不得标记为已通过集成测试。
