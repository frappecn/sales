# 项目总览

## 项目定位
Sales 是基于 Frappe Framework 和 ERPNext 扩展开发的即时零售运营管理系统，目标是支持以仓为履约中心的线上零售业务。

## 产品参考
业务形态参考小象超市、叮咚买菜、朴朴超市等即时零售模式，包括线上选购、订单分配、仓内拣货、复核打包和即时配送。参考对象用于理解业务，不代表复制其内部系统或商业规则。

## 核心业务链路
供应商采购 → 收货入库 → 仓间调拨与补货 → 消费者下单 → 订单分配 → 拣货 → 复核打包 → 出库交接 → 骑手配送 → 签收/售后 → 财务核算 → 经营分析。

## 首期方向
优先验证自营前置仓模式能否完整跑通。经营主体、区域、门店/前置仓数量、配送方式、支付方式和经营国家/地区仍以待确认清单为准。

## 设计目标
- 支持多区域、多门店/前置仓的组织管理。
- 支持商品、价格、库存、采购、订单和履约协同。
- 支持消费者端与仓内作业端等多终端。
- 通过 ERPNext 处理标准库存与财务交易。
- 保留未来扩展中央仓、实体门店和第三方商家的能力，但不提前实现未经确认的复杂场景。

## 非目标
首期不以拆分微服务、建设复杂数据中台或替换 ERPNext 标准账务为目标。离线收银、复杂自动调度、第三方平台聚合等能力需单独评估。
